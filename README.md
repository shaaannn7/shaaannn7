## Projects

### [Sentinel](https://github.com/shaaannn7/sentinel) — Email forensics & threat analysis platform

An open-source SOC investigation tool for analysing suspicious email messages. It accepts raw `.eml` files and produces a structured investigation: parsed MIME evidence, authentication results (SPF/DKIM/DMARC), threat scoring, delivery timelines, indicator enrichment, and optional AI-assisted triage. The platform is deterministic-first — scoring and parsing drive decisions, with AI providing supplementary context rather than opaque verdicts.

`Python` · `FastAPI` · `Docker` · `PostgreSQL` · `Redis` · `SQLite`

---

### [KrishiMitra](https://github.com/shaaannn7/KrishiMitra) — Agriculture super-app for Indian farmers

A full-stack application built for Indian farmers. Features include micro-local weather forecasts with agricultural alerts, AI-assisted crop disease diagnosis from leaf photos, a government welfare scheme matcher, a farm ledger for tracking costs and harvest income, a community Q&A forum, and a peer-to-peer agricultural marketplace. Built as a Progressive Web App with a mobile-first design.

`Next.js` · `FastAPI` · `Python` · `PostgreSQL` · `SQLAlchemy` · `Tailwind CSS` · `Docker`

---

### [TechVault](https://github.com/shaaannn7/TechVault) — College resource platform · [Live](https://tech-vault-three.vercel.app)

A web platform for organising and sharing academic resources — notes, PDFs, previous-year question papers — structured around JECRC/RTU engineering courses. Built with a React frontend and a Node.js/Express backend backed by MongoDB. Includes a fail-safe mock database mode so the app remains usable during connectivity issues.

`React 19` · `Node.js` · `Express` · `MongoDB` · `Vercel` · `Render`

---

### [Smart Canteen](https://github.com/shaaannn7/Smart-Canteen-) — Real-time institutional ordering system

A queue-elimination platform for college canteens. Students browse menus, place orders, and track their status live. The kitchen dashboard receives orders in real time and pushes status updates back to clients with sub-100ms Socket.io events. Uses an event-driven decoupled architecture: Next.js frontend, Node.js/Express REST API, and a Socket.io gateway.

`Next.js` · `Node.js` · `Express` · `Socket.io` · `MongoDB`

---

### [Smart Language Lab](https://github.com/shaaannn7/Smart-Language-Lab) · [Live](https://languagelab-gamma.vercel.app)

An interactive web application for language learning. Built with Next.js and TypeScript.

`Next.js` · `TypeScript` · `Vercel`
